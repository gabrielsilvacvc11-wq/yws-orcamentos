# YWS Orçamentos

Gerador profissional de orçamentos para projetos de **Energia Solar** e **Serviços Elétricos**.

## Funcionalidades

- Dados do cliente (nome, CPF/CNPJ, telefone, e-mail, endereço)
- Tipos de projeto pré-definidos (Solar, Instalação Elétrica, Limpeza de Painéis, etc.)
- Tabela dinâmica de itens (adicionar/remover)
- Cálculo automático de subtotal, desconto e impostos
- Salvamento local (histórico no navegador)
- Impressão / geração de PDF profissional
- Envio rápido via WhatsApp
- Interface moderna e responsiva

## Como usar

1. Acesse o site
2. Preencha os dados do cliente e do projeto
3. Adicione os itens com quantidades e valores
4. Ajuste desconto e impostos se necessário
5. Salve, imprima ou envie pelo WhatsApp

## Deploy

- GitHub Pages: ative nas configurações do repositório (Settings → Pages → Deploy from main branch)
- Ou use Vercel / Netlify
